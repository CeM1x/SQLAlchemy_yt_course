# SQLAlchemy_yt_course

Этот репозиторий содержит мой учебный практический опыт с SQLAlchemy, основанный на разборе и повторении одного учебного проекта, похожего на систему типа «headhunter». Цель — понять, как работает SQLAlchemy и как строятся полноценные проекты с использованием ORM и Core.

Важно: исходный проект не мой, я переписывал и повторял его для изучения, чтобы освоить концепции SQLAlchemy на практике.

Что изучено
- Работа с SQLAlchemy ORM и Core
- Организация структуры проекта с разделением моделей, схем и запросов
- Настройка базы данных и подключение через config.py и database.py
- Создание моделей в models_core.py и models_orm.py
- Работа с CRUD-операциями через queries/core.py и queries/orm.py
- Использование сессий, транзакций и зависимостей между таблицами
- Работа со схемами данных через schemas.py
- Практика проектирования архитектуры кода для масштабируемых проектов
